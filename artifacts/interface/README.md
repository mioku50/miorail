# @mioagent/interface

Still's web app, served at <https://miorail.xyz>: Home, Assets, Agent, Stocks and
More, Get money, Repay and the lending review, Spend, and Swap AI. In the Base
App and Farcaster it is also the mini app.

Shared screens live in `lib/ui`; wallet calls and Builder Code attribution in
`lib/wallet-actions`. The API it talks to is `artifacts/api-server`, and the
production build gets the public Builder Code from `ops/deploy.sh`.
